1. Significant Figures

Significant figures (sig figs) are the digits in a measured or calculated value that carry real, meaningful information about its precision. When you write a measurement down, the number of sig figs you use is a claim about how well you actually know that number.

Counting rules

  • All non-zero digits are significant (2.35 has 3 sig figs).
  • Zeros between non-zero digits are significant (105 has 3 sig figs).
  • Leading zeros are never significant — they just locate the decimal point (0.0042 has 2 sig figs).
  • Trailing zeros after a decimal point are significant (7.30 has 3 sig figs).
  • Trailing zeros with no decimal point are ambiguous (2500 could be 2, 3, or 4 sig figs) — scientific notation removes the ambiguity (2.500 × 10³ is unambiguously 4 sig figs).

Rounding rule

When you round a calculated result, keep only as many sig figs as your least precise input allowed. A chain of calculations is only as precise as its weakest link.

Worked Example How many sig figs does 0.03080 have?
The leading zeros (0.0) are not significant. The 3, 0, 8 are significant (nonzero and between/after nonzero digits), and the trailing 0 after the decimal point is significant. Answer: 4 sig figs.

2. Precision vs. Accuracy

Precision describes how close repeated measurements are to each other — it's about consistency and reproducibility, regardless of whether the value is correct.

Accuracy describes how close a measurement is to the true or accepted value.

A set of measurements can be precise without being accurate (consistently wrong, e.g., from a miscalibrated instrument), accurate without being precise (scattered, but averaging close to correct), both, or neither. The two are independent properties.

Problem 2.1A digital scale always reads exactly 2.0 g heavier than the true mass of an object, every single time you weigh something on it. Is this scale precise? Is it accurate? Explain.
Problem 2.2Four students each measure the length of the same table five times. Student A's five values are tightly clustered but 3 cm below the table's actual (known) length. Student B's five values are scattered widely, but their average lands almost exactly on the actual length. Which student is more precise? Which is more accurate?
Problem 2.3A third student, Student C, gets five values that are both widely scattered and centered noticeably away from the table's true length. Where does Student C fall on the precision/accuracy picture compared to Students A and B? Is it possible to be neither precise nor accurate?

3. Error and the Least Count of a Measuring Device

Every measuring instrument has a least count: the smallest division it can actually resolve. This is not a mistake or a flaw — it is a fundamental limit built into the device itself, and it exists even when you measure something perfectly carefully.

Uncertainty of a single measurement = ± (least count of the instrument)

Any measurement should be reported as (reading ± least count), never as a bare number with no stated uncertainty.

Worked Example — Same Physical Ruler, Different Graduations Suppose two rulers are used to measure the same 7.4 cm object.
Ruler A is only graduated in whole centimeters (its smallest division is 1 cm). Its least count is 1 cm, so a measurement on this ruler must be reported as (7 ± 1) cm.
Ruler B is graduated in millimeters (its smallest division is 1 mm = 0.1 cm). Its least count is 0.1 cm, so the same object measured on this ruler is reported as (7.4 ± 0.1) cm.
Ruler B is 10 times more precise than Ruler A, purely because of how finely it is graduated — not because anyone measured more carefully. The least count is a property of the tool, not the person using it.
Problem 3.1A digital stopwatch displays time to the nearest 0.01 s. A wall clock with a sweeping second hand can reasonably be read to the nearest 1 s. If both are used to time the same 12-second event, how should each result be reported?

Problem 3.3The same small metal rod is measured two ways: with an ordinary ruler (least count 0.1 cm) and with a vernier caliper (least count 0.01 cm). The rod's true length is 3.47 cm. How would each instrument report this measurement?

4. Error Propagation: Area of a Rectangle

Suppose you measure the length and width of a rectangle: L = L₀ ± ΔL and B = B₀ ± ΔB, where ΔL and ΔB are each instrument least counts (small compared to L₀ and B₀). What is the uncertainty in the calculated area, A = L × B?

Derivation (algebra only — no calculus)

Write each measured quantity as its central value plus its uncertainty:
A = (L₀ ± ΔL)(B₀ ± ΔB)
Multiply this out term by term:
A = L₀B₀ ± L₀ΔB ± B₀ΔL + ΔLΔB
The last term, ΔLΔB, is a product of two small quantities — it is much smaller than the other terms (a "second-order" term) and can be dropped:
A ≈ L₀B₀ ± (L₀ΔB + B₀ΔL)
So the absolute uncertainty in area is ΔA = L₀ΔB + B₀ΔL. Dividing both sides by A₀=L₀B₀ gives the more useful relative form:
ΔA / A = ΔL / L + ΔB / B

In words: when quantities are multiplied, their relative (fractional) uncertainties add.

Worked Example L = (12.4 ± 0.1) cm, B = (8.2 ± 0.1) cm.
A₀ = 12.4 × 8.2 = 101.68 cm².
ΔA/A = (0.1/12.4) + (0.1/8.2) = 0.0081 + 0.0122 = 0.0203, about 2.0%.
ΔA = 101.68 × 0.0203 = 2.06 cm².
Reported: A = (101.7 ± 2.1) cm². (Check: multiplying out the extreme values (12.5)(8.3) = 103.75, matching our approximation of 101.68+2.06=103.74 to within the rounding — confirming the dropped second-order term really was negligible.)
Problem 4.1A phone screen is measured as L = (147.0 ± 0.5) mm and B = (72.0 ± 0.5) mm. Find the area and its uncertainty.
Problem 4.2A rectangular garden plot is measured with a tape whose least count is 5 cm: L = (450 ± 5) cm, B = (300 ± 5) cm. Find the area and its uncertainty, and express the relative uncertainty as a percent.

5. Error Propagation: Volume of a Rectangular Box

The same idea extends naturally to volume, V = L × B × H, with three measured quantities instead of two.

V = (L₀±ΔL)(B₀±ΔB)(H₀±ΔH)
Multiplying this out produces one "zeroth-order" term (L₀B₀H₀), three "first-order" terms (each with exactly one Δ), and several "second-order and third-order" terms (each with two or three Δ's multiplied together, e.g., ΔLΔB, or ΔLΔBΔH). Note: Multiply and explicitly show all terms and check with instructor before proceeding further.
As before, every term with more than one Δ is a product of small quantities and is dropped. Only the three first-order terms survive:
ΔV = ΔL·B₀H₀ + L₀·ΔB·H₀ + L₀B₀·ΔH
Dividing through by V₀=L₀B₀H₀:
ΔV / V = ΔL / L + ΔB / B + ΔH / H

The pattern continues exactly as expected: one relative-uncertainty term per multiplied quantity.

Worked Example L = (12.4 ± 0.1) cm, B = (8.2 ± 0.1) cm, H = (5.5 ± 0.1) cm.
V₀ = 12.4 × 8.2 × 5.5 = 559.2 cm³.
ΔV/V = (0.1/12.4)+(0.1/8.2)+(0.1/5.5) = 0.0081+0.0122+0.0182 = 0.0384, about 3.8%.
ΔV = 559.2 × 0.0384 = 21.5 cm³.
Reported: V = (559 ± 22) cm³.

6. The General Rule for Propagation of Errors

Sections 4 and 5 both followed the same pattern. We can now state it formally, without reference to any specific shape.

Rule 1 — Sums and differences: absolute uncertainties add

If z = x + y, then z₀±Δz = (x₀±Δx) + (y₀±Δy) = (x₀+y₀) ± (Δx+Δy).
There is no cross-term to drop here — the result is already exact. The same holds for subtraction, z = x − y.
z = x ± y   ⇒   Δz = Δx + Δy  (absolute uncertainties always add, even for a difference)

Rule 2 — Products and quotients: relative uncertainties add

This is exactly what Sections 4 and 5 derived for A = L×B and V = L×B×H. The same algebra (expand, then discard every term with two or more Δ's) applies to any product of measured quantities, and to quotients as well:

z = xy  or  z = x/y   ⇒   Δz / z = Δx / x + Δy / y

For a product of any number of quantities (z = xyw...), one relative-uncertainty term is added per quantity multiplied — exactly the pattern seen going from two factors (area) to three factors (volume).

A useful special case: powers

Since x² is just x·x (the same quantity multiplied by itself), Rule 2 says its relative uncertainty term appears twice:

z = x²   ⇒   Δz / z = 2(Δx / x)

More generally, for z = xⁿ, the relative uncertainty in z is n times the relative uncertainty in x.

Worked Example — Combining Both Rules The perimeter of the Section 4 rectangle is P = 2L + 2B (a sum, so Rule 1 applies to each piece): with L=(12.4±0.1) cm and B=(8.2±0.1) cm,
ΔP = 2ΔL + 2ΔB = 2(0.1) + 2(0.1) = 0.4 cm. P₀ = 2(12.4)+2(8.2) = 41.2 cm.
Reported: P = (41.2 ± 0.4) cm. Notice this uses Rule 1 (absolute uncertainties add), not Rule 2 — because perimeter is built from addition, not multiplication.

7. Conclusion & Key Takeaways

Significant Figures

Sig figs communicate how precisely a number is actually known. A calculated result can never be more precise than its least-precise input.

Precision vs. Accuracy

Precision is consistency (repeatability); accuracy is correctness (closeness to the true value). A measurement can have either, both, or neither.

Least Count

Every instrument has a built-in resolution limit. The uncertainty of a single reading equals that instrument's least count — report every measurement as (value ± least count).

Propagating Errors

Sums/differences: absolute uncertainties add.
Products/quotients: relative uncertainties add. Both rules come from simple algebra: expand, then discard the small leftover terms built from two or more uncertainties multiplied together.

Every calculated quantity in this course — areas, volumes, velocities, forces — is built from measured inputs, and every measured input carries some uncertainty. Knowing how that uncertainty moves through a calculation is what turns a bare number into a scientifically meaningful result.

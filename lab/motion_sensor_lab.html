Physics Lab: Motion Sensor Fun

PHYS203 General Physics I · Fall 2026

Preliminaries

  • See that you have a motion detector (green or blue) plugged into a Vernier LabPro interface, and this in turn connected via a USB cable to the computer.
  • Start up Logger Pro: (Start / All Programs / Vernier / Logger Pro)
  • If the motion detector and LabPro are properly attached, Logger Pro will automatically set up graphs for velocity and position.
  • Aim the sensor across the table, click the collect button, and move something toward and away from it. Note that it only senses in a cone out in front, it senses the closest object that reflects ultrasound, and it doesn't work closer than about 40 cm for the blue sensors and 15 cm for the green ones.
  • On the Moodle page for PHYS 203 General Physics (not the PHYS 203 Lab page), under Lab Materials, find the folder Lab 2 Files for Logger Pro. Click on it and then click to download the folder. It will be a compressed folder. Find it in your Downloads folder, right-click on it, and extract all files. You can then delete the compressed folder.

A Little Fun

Now in Logger Pro, go to File | Open, then navigate to your Downloads folder, where you should see all the files you just downloaded. Open the file GC Position Match 1 Green (or Blue, depending on the color of your motion detector). It should set up the graphs showing a plot line that you try to copy by moving the object. Take turns matching the curve. Get some good ones you can be proud of. Show your instructor. Then work through the other files and try to match those curves.

You should work on the following files. For each one, get a good result and show your instructor. Be sure both partners (or all three) succeed in getting a reasonably good result on each file.

  • GC Position Match 1 Green or Blue
  • GC Position Match 2 Green or Blue
  • GC Position Match Custom *
  • GC Velocity Match 1
  • GC Velocity Match 2
  • GC Velocity Match Custom *

* For the custom files, while one of you looks away, the other records a run with interesting motions. Then do Experiment | Store Latest Run, and then the other member can try to copy what you did.

Freefall

Open the file GC zBall Toss.cmbl.

Set the sensor on the table or the floor, aiming straight up.

Toss a ball straight up over the sensor. Be sure to pull your hands back immediately. Try this until you get a nice plot which should include a nice long parabolic section. (Another method you may try instead is to hold the sensor up above while tossing a ball underneath it. Be sure to hold it very still.)

Look at the data. There are only parts of it that are freefall. Find them. Does the plot make sense? Can you explain most of the details?

  1. 1Click and drag to highlight a freefall portion of the acceleration plot. Then under Analyze | Statistics, see if you get what you expect. In particular, does the mean value have a special meaning?
  2. 2Highlight a freefall portion of the velocity plot and use Analyze | Linear Fit to investigate. Do the parameters of this line have any special meanings? Can you explain what both parameters (m and b) represent?
  3. 3Lastly, highlight a freefall portion of the distance plot. Use Analyze | Curve Fit and then choose a quadratic. Can you explain all the coefficients of the fit? See if you can explain the physical meaning of each coefficient (A, B, and C) and tell your instructor. (For example, if B = 23, what does that mean? What physical thing is 23, and what are the units?) Once you understand the coefficients, check the box called "time offset." Now the fit uses a shifted time axis that starts at the beginning of the highlighted region. The coefficients should all now have a more useful meaning, which should be clear to you.
